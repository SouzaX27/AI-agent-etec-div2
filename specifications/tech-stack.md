# Stack tecnológica

- TypeScript como linguagem principal.
- React para a interface do site institucional.
- Node.js para a camada de aplicação e APIs.
- SQLite para persistência inicial de dados e conteúdos do painel administrativo.
- CSS responsivo para suporte a navegadores modernos e dispositivos móveis.

A arquitetura tem foco em simplicidade, confiabilidade e rapidez de desenvolvimento para um site institucional com catálogo e notícias.
